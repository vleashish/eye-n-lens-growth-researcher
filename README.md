# EYE N LENS Hermes Growth Skill

## Installation

Copy the skill folder into the skills directory used by your Hermes installation.

Core file:
SKILL.md

Reference files:
references/brand.md
references/sources.md
references/scoring.md

Templates:
templates/daily_research.md
templates/competitor_record.md

Data:
data/performance.csv

## First setup

1. Confirm Hermes can browse/search the web.
2. Add the skill to Hermes.
3. Review `references/brand.md`.
4. Add exact current EYE N LENS product specifications separately if available.
5. Add current offers separately; do not place temporary offers in permanent brand instructions.
6. Export Instagram/Facebook analytics periodically and append them to `data/performance.csv`.
7. Run:

Run EYE N LENS Growth Research

Run EYE N LENS Weekly Review

## Important

This skill does not guarantee viral performance.

Its purpose is to make research evidence-driven, current, repeatable and connected to business outcomes.

Never publish unverified prices, offers, product specifications, medical claims or testimonials.
